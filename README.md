# Student Result Analyzer

Overview
This is a beginner-level Python project designed to analyze student performance. The program takes input marks, calculates total and percentage, and assigns grades based on predefined conditions.

 Features
- Accepts user input for multiple subjects
- Calculates total marks and percentage
- Assigns grades using conditional statements (if-else)
- Supports multiple student entries using loops

## Technologies Used
- Python
- Basic Programming Concepts (Loops & Conditionals)

## Purpose
This project demonstrates the use of fundamental Python concepts in building a simple, real-world application. It is ideal for beginners starting their programming journey.
